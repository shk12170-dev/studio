# Moment Studio

로그인 없이 쓰는 이미지·문구 합성 도구입니다. 이미지(PNG/JPEG)에 문구를 얹어 1:1, 4:5, 9:16 비율의 PNG로 저장합니다.

- 실행: `index.html`을 브라우저에서 열거나 정적 호스팅(GitHub Pages 등)에 올립니다. 서버·DB 없음.
- 업로드: PNG/JPEG만 허용(MIME + 파일 시그니처 검사). 거부되면 사유를 보여주고 기존 작업을 유지합니다.
- 미리보기와 다운로드는 같은 캔버스·같은 렌더 함수를 사용합니다. 폰트 로딩이 끝나야 다운로드할 수 있습니다.
- 템플릿: 고유 UUID로 저장(localStorage), 새로고침 후에도 유지. JSON 내보내기/가져오기 지원(가져올 때 값 검증).
- 개인정보: 이미지는 브라우저 안에서만 처리되며 서버로 전송되지 않습니다. 캔버스 재인코딩으로 원본 EXIF는 저장 PNG에 포함되지 않습니다.
- 자체 검사: 화면의 "극단 입력 12건 자동 검사" 버튼으로 12건을 실행합니다.
